# GPS Module
## IO Ports
The GPS module defines 3 IO ports

| Name | Id | Function - get                                      | Function - set |
|------|----|-----------------------------------------------------|----------------|
| X    | 0  | Gets the x coordinate of the robot's block position | N/A            |
| Y    | 1  | Gets the y coordinate of the robot's block position | N/A            |
| Z    | 2  | Gets the z coordinate of the robot's block position | N/A            |
