# Hard Drive Module
## IO Ports
The hard drive module defines 2 IO ports

| Name    | Id | Function - get                                          | Function - set                                          |
|---------|----|---------------------------------------------------------|---------------------------------------------------------|
| Address | 0  | Gets the address used for the other IO port             | Sets the address used for the other IO port             |
| Value   | 1  | Gets the byte in the hard drive's memory at the address | Sets the byte in the hard drive's memory at the address |
